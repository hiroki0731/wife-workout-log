# 自宅筋トレ記録（スマホ版）

自宅での筋トレを記録するWebアプリ。Mac版と同じ仕様をスマホ向けにしたもの。
ホーム画面に追加して使う。

- 本体は `index.html` の1ファイル（ビルド不要）。`sw.js` は電波がなくても開けるようにするためのもの。
- 記録はスマホのブラウザの中（localStorage）に保存する。連携していれば、記録するたびにGoogleスプレッドシートへ丸ごと写しを送る（下記）。ファイルへの書き出し・読み込みも残してある。
- スプレッドシートへの写し：受け口は `gas/Code.gs`（スプレッドシートに付けた Google Apps Script をウェブアプリとして公開する）。`KEY` の合言葉はリポジトリには入れず、貼り付けるときに入れる。アプリには「種目と目標」タブで連携コード（`{"u": 受け口のURL, "k": 合言葉}` のJSONをbase64にしたもの）を貼る。
  - 写しは1日1行・90日分。送れなかったら未送信の印を残し、開いたときと電波が戻ったときに送り直す。
  - 記録が空のスマホで連携したときは上書きせず、戻す日を選ばせる。
  - 連携の設定は別の保存名 `home-workout-log-web:sync` に置く。
- アイコンは `swift make_icon.swift` で作り直せる。
- 画面確認：`index.html?demo` でサンプルの記録を表示する（保存はしない）。`&tab=history` `&tab=settings` でタブを指定できる。`&day=-1` で前の日から開く、`&celebrate=clear`（または goal）で開いた直後にお祝いの紙吹雪を出す。
- 記録の保存名（localStorage のキー `home-workout-log-web:v1`）は変えない。変えると、それまでの記録が読めなくなる。
- 種目を足すときは、`INITIAL` に足したうえで `ADDED` にも書く。保存済みの種目一覧がそのまま使われるため、`INITIAL` を変えるだけでは反映されない。`ADDED` の種目には足した日が `since` として付き、それより前の日はその種目がなくてもクリアと判定する。
- 公開先：GitHub Pages。直したら push すれば、次に開いたときに新しい版になる。
