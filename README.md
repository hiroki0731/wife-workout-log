# 自宅筋トレ記録（スマホ版）

自宅での筋トレを記録するWebアプリ。Mac版と同じ仕様をスマホ向けにしたもの。
ホーム画面に追加して使う。

- 本体は `index.html` の1ファイル（ビルド不要）。`sw.js` は電波がなくても開けるようにするためのもの。
- 記録はスマホのブラウザの中（localStorage）だけに保存する。サーバーには何も送らない。バックアップは「種目と目標」タブの書き出し・読み込み。
- アイコンは `swift make_icon.swift` で作り直せる。
- 画面確認：`index.html?demo` でサンプルの記録を表示する（保存はしない）。`&tab=history` `&tab=settings` でタブを指定できる。`&day=-1` で前の日から開く、`&celebrate=clear`（または goal）で開いた直後にお祝いの紙吹雪を出す。
- 記録の保存名（localStorage のキー `home-workout-log-web:v1`）は変えない。変えると、それまでの記録が読めなくなる。
- 種目を足すときは、保存済みの種目一覧に新しい種目を足す処理も書く（保存済みの一覧がそのまま使われるため、`INITIAL` を変えるだけでは反映されない）。
- 公開先：GitHub Pages。直したら push すれば、次に開いたときに新しい版になる。
